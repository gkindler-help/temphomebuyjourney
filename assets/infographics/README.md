# Infographics Folder

## Purpose
Visual breakdowns for articles to increase engagement and social sharing.

## File Naming Convention
```
affordability-[salary]k-infographic.jpg
Example: affordability-70k-infographic.jpg
```

## Recommended Specs
- **Format:** JPG or PNG
- **Dimensions:** 1200px x 1800px (2:3 ratio, mobile-friendly)
- **File size:** 200-300 KB (optimized for web)
- **Style:** Match site colors (gold #ffcc4d, dark bg #050505)

## What to Include in Each Infographic
1. **Header:** "How Much House Can You Afford Making $XXK in St. Louis?"
2. **Salary breakdown:** Gross income → Max housing → Max debt
3. **PITI breakdown:** Principal, Interest, Taxes, Insurance (pie chart or bar)
4. **3 Neighborhoods:** Name, median price, schools (visual cards)
5. **Debt impact:** Before/after visual showing car payment effect
6. **Down payment options:** VA 0%, FHA 3.5%, Conv 5%/20%
7. **Footer:** STL Home Journey logo + George Kindler contact

## Design Tools
- **Canva:** Easy templates (use Pro for brand kit)
- **Figma:** More control, professional
- **Photoshop:** Full custom design
- **Visme/Piktochart:** Infographic-specific tools

## Once Created
1. Export as JPG (optimized)
2. Save to this folder
3. Open article HTML
4. Find `<!-- REAL INFOGRAPHIC -->` comment
5. Uncomment the `<img>` tag
6. Delete the placeholder `<div>`
7. Test on mobile and desktop
